How it works

1. python3 scripts/fetch_data.py — pulls NEAR BigQuery + Intents Explorer data (set INTENTS_API_JWT and GCP credentials for live data).

2. python3 scripts/build_charts.py — rebuilds every chart from raw data.

3. python3 scripts/seal_results.py — seals data, charts, and thesis into the NEAR 231-gate sealed log at redsigma.testnet.

4. Verify any entry: near view redsigma.testnet verify_entry '{"entry_id":<id>,"action_data":"<data>\"}' → true intact, false tampered.
